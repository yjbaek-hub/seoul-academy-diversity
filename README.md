# 학원가는 도시의 다양성이 낮을까?

스마트시티 융합기술세미나 | 과제3 — **도시 현상을 지표로 측정하고 공간적으로 해석하기**

서울 400개 행정동의 2026년 2분기 추정 매출로 학원가의 업종 다양성을 측정했다.

> **한 줄 요약** — 학원가의 업종 다양성은 학원을 포함하면 다소 낮지만(Gini–Simpson 중앙값 0.871 대 0.890), 학원을 제외하면 서울의 다른 동과 차이가 거의 없다(0.896 대 0.885). 학원 특화 동은 준주거·상업지역이 아니라 제3종일반주거(중·고층 주택 중심) 비율이 높다(51% 대 23%).

## 지표

| 지표 | 내용 |
|---|---|
| 학원 입지계수 LQ | 동 매출 중 일반교습학원 비중 ÷ 서울 전체 비중 |
| 학원 밀도 | 일반교습학원 매출 ÷ 0~19세 생활인구 (만 원/인/분기) |
| 업종 다양성 Gini–Simpson | 1 − Σ(업종 비중)², 학원 제외 값도 함께 계산 |
| 용도지역 비율 (보조 변수) | 전용·제1·2종일반주거 / 제3종일반주거 / 준주거·상업 |

## 사용 자료

- 서울 열린데이터광장 상권분석서비스 추정매출 (행정동 × 업종 × 분기, 2026년 2분기)
- 서울 열린데이터광장 행정동별 연령별 생활인구 (2026년 4~6월)
- 행정동 경계 `HangJeongDong_ver20250101.geojson` (수업 자료)
- 도시계획정보서비스(UPIS) 용도지역(도시지역)

원자료는 용량 때문에 저장소에 포함하지 않았다. 노트북에는 계산 과정과 실행 결과가 들어 있다.
